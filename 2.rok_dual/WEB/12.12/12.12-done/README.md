# Pokyny
1. Otvorit VS Code
1. Kliknut na File > Open Folder > (Tu si vytvorte priecinok so svojim priezviskom) > Vytvorte priecinok s dnesnym datumom
1. Kliknite na Select Folder
1. V lavom paneli vo VS Code vytvorte 2 subory
    * index.html
    * main.css
1. Otvorte stranku cez Live server doplnok (CTRL + SHIFT + P) > Open With Liver Server
